# Yung Network

Landing page responsive in HTML, CSS e JavaScript vanilla, ispirata al render fornito.

## Avvio
Apri `index.html` nel browser. Nessuna dipendenza da installare.

## File
- `index.html` — struttura, contenuti e piccole interazioni (menu mobile e pulsanti copia).
- `style.css` — stile neon/cyberpunk e layout responsive.

I link social sono segnaposto: sostituiscili con gli URL ufficiali. Il progetto usa Google Fonts per Barlow Condensed e Orbitron; se non disponibili, usa font di fallback.
